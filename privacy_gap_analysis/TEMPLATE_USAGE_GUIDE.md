# Professional Compliance Report Template System

This system generates professional compliance reports in multiple formats using the **Audit Caddie CCPA Compliance Report** as the template standard.

##  Overview

The template system creates beautifully formatted reports with:
- **Professional cover page** with company branding
- **Executive summary** section
- **Metadata** (generated by, analysis date)
- **Structured sections** with consistent styling
- **Color-coded priorities** for findings
- **Multiple output formats**: Markdown, Word (.docx), PDF

##  Template Features

Based on the `Audit Caddie CCPA Compliance Report.docx` template:

### Cover Page
- Company name header
- Compliance score indicator
- Report title (centered, large blue text)
- Subtitle
- Executive summary box
- Metadata fields (Generated By, Analysis Date)

### Styling
- **Colors**:
  - Primary: RGB(0, 51, 102) - Dark blue
  - Secondary: RGB(0, 112, 192) - Blue
  - Accent: RGB(68, 114, 196) - Light blue
- **Fonts**: Calibri throughout
- **Heading Hierarchy**:
  - H1: 18pt, bold, blue (major sections)
  - H2: 14pt, bold, light blue (subsections)
  - H3: 12pt, bold, dark blue (metadata labels)
  - Body: 11pt, 1.5 line spacing

##  Quick Start

### Method 1: Generate from Markdown

```bash
cd scripts
python generate_compliance_report.py \
  --markdown ../reports/your_report.md \
  --company "Your Company Name" \
  --output-dir ../reports
```

### Method 2: Use in Python Code

```python
from compliance_report_template import ComplianceReportTemplate

# Create report
report = ComplianceReportTemplate()

# Add cover page
report.add_cover_page(
    company_name="Audit Caddie",
    report_title="CCPA COMPLIANCE ASSESSMENT REPORT",
    subtitle="Privacy Policy Compliance Gap Analysis",
    executive_summary="Your summary here...",
    generated_by="Privacy Policy Gap Analysis System",
    analysis_date="December 27, 2025"
)

# Add content
report.add_section_header("EXECUTIVE SUMMARY")
report.add_paragraph("Your analysis content...")

# Add gaps
report.add_gap_finding(
    title="Right to Know Disclosure",
    description="The policy does not explicitly provide...",
    priority="High"
)

# Save
report.save("output/report.docx")
```

### Method 3: Convert Existing Markdown

```python
from compliance_report_template import convert_markdown_to_compliance_report

metadata = {
    'company_name': 'Audit Caddie',
    'report_title': 'CCPA COMPLIANCE ASSESSMENT REPORT',
    'subtitle': 'Privacy Policy Gap Analysis',
    'executive_summary': 'Analysis summary...',
    'generated_by': 'Privacy Analysis System',
    'analysis_date': 'December 27, 2025'
}

docx_path = convert_markdown_to_compliance_report(
    'reports/analysis.md',
    output_file='reports/professional_report.docx',
    metadata=metadata
)
```

##  Available Classes and Functions

### ComplianceReportTemplate Class

Main class for building professional reports.

#### Methods:

- **`add_cover_page(...)`** - Add professional cover page
- **`add_section_header(title)`** - Add major section (H1)
- **`add_subsection(title, content)`** - Add subsection (H2)
- **`add_paragraph(text, bold)`** - Add formatted paragraph
- **`add_bullet_list(items)`** - Add bulleted list
- **`add_gap_finding(title, description, priority)`** - Add compliance gap with priority coloring
- **`add_table_of_contents(sections)`** - Add TOC
- **`save(filepath)`** - Save document

#### Class Methods:

- **`from_markdown(markdown_content, metadata)`** - Create from markdown

### Helper Functions

- **`convert_markdown_to_compliance_report(md_file, output_file, metadata)`**
- **`generate_pdf_report(markdown_file, docx_file, pdf_file, metadata)`**

##  Customization

### Priority Colors

Gap findings support priority levels with automatic color coding:

```python
report.add_gap_finding(
    title="Critical Gap",
    description="Description...",
    priority="High"  # Red text
)
```

- **High/Critical**: Red RGB(192, 0, 0)
- **Medium**: Orange RGB(192, 128, 0)
- **Low**: Green RGB(0, 128, 0)

### Custom Metadata

Full metadata structure:

```python
metadata = {
    'company_name': 'Company Name',
    'report_title': 'COMPLIANCE ASSESSMENT REPORT',
    'subtitle': 'Privacy Policy\nCompliance Gap Analysis',
    'executive_summary': 'Summary text...',
    'generated_by': 'Analysis System Name',
    'analysis_date': 'December 27, 2025'
}
```


### Lists
```markdown

- Bullet point 3
```

### Formatting
```markdown

```

##  Complete Workflow Example

```python
from generate_compliance_report import ComplianceReportGenerator

# Initialize generator
generator = ComplianceReportGenerator(output_dir='reports')

# Prepare analysis data
analysis_data = {
    'summary': 'Executive summary of findings...',
    'gaps': [
        {
            'title': 'Right to Know Disclosure',
            'description': 'The policy does not explicitly...',
            'priority': 'High'
        },
        {
            'title': 'Data Retention Policies',
            'description': 'The policy does not specify...',
            'priority': 'Medium'
        }
    ],
    'recommendations': [
        'Add explicit right to know disclosure',
        'Define data retention periods'
    ],
    'priority_actions': [
        'Update privacy policy within 30 days',
        'Implement consumer rights request process'
    ]
}

# Generate all formats
files = generator.create_report_from_analysis(
    company_name='Audit Caddie',
    analysis_data=analysis_data,
    compliance_type='CCPA'
)

# Output: files = {'markdown': 'path/to/file.md',
#                  'docx': 'path/to/file.docx',
#                  'pdf': 'path/to/file.pdf'}
```

##  PDF Generation

### Requirements

PDF generation requires LibreOffice (macOS/Linux) or docx2pdf (Windows).

#### Install LibreOffice (macOS):
```bash
brew install --cask libreoffice
```

#### Install LibreOffice (Linux):
```bash
sudo apt-get install libreoffice
```

#### Install docx2pdf (Windows):
```bash
pip install docx2pdf
```

### Generate PDF

```bash
# From markdown
python report_pdf_generator.py report.md report.pdf

# From Word document
python report_pdf_generator.py report.docx report.pdf
```

##  Best Practices

1. **Always provide metadata** - Creates professional cover pages
2. **Use consistent heading levels** - Maintains document structure
3. **Include priority levels** - Helps stakeholders prioritize actions
4. **Generate all formats** - Markdown for source, Word for editing, PDF for distribution
5. **Follow naming conventions** - Use `CompanyName_Type_Report_YYYYMMDD.ext`

##  Troubleshooting

### PDF Generation Fails
**Solution**: Install LibreOffice or ensure it's in your PATH

### Formatting Issues
**Solution**: Check that markdown follows supported conventions (see Markdown Formatting section)

### Missing Metadata
**Solution**: All metadata fields are optional but recommended for professional output
